# Construction Management App

A React-based web application for managing and tracking construction site activities.

## Features
- **Dashboard:** Overview of site information, location, and assigned supervisors.
- **Daily Work Tracking:** Keep track of daily activities and progress.
- **Expense Management:** Track construction-related expenses.
- **Authentication:** Secure login and protected routes.

## Technologies Used
- React
- Vite
- React Bootstrap

## Setup and Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Sagar-BCS/construction-react.git
   ```

2. **Install dependencies:**
   Navigate into the project directory and run:
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.
